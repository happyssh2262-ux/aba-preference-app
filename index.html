짝 자극 제시 선택 (Paired-Stimulus Preference Assessment)

모든 자극 쌍을 1:1로 짝지어 제시하고 학생이 선택한 자극 버튼을 터치해 승률을 산출합니다.

자극 대체 있는 중다 자극 제시 선택 (MSW)

선택된 자극은 다음 회기에도 유지하고, 선택되지 않은 자극은 예비 풀의 새 자극으로 교체하여 제시합니다.

전체 자극 예비 풀 (클릭하여 이름 수정 가능)
1회기 제시 중 남은 대체 예비 항목: 0개

회기별 선택 이력 (클릭하여 선택 항목 수정 가능)

자극 대체 없는 중다 자극 제시 선택 (MSWO)

선택된 자극을 배열에서 제거하고 남은 자극들의 위치를 재배열하여 1순위부터 마지막 순위까지 연속으로 도출합니다.

1라운드 진행 중 (1순위 선택 차례)
현재 선택 순서: 없음

완료된 라운드별 순위 기록 (드롭다운으로 순위 수정 가능)

MSWO 통합 평균 순위 요약
최종순위 자극명 평균 순위 1위 횟수
※ 중요 안내 (자극 선호도 평가 vs 강화제 평가): 본 종합 결과 리포트는 실제 강화 효과를 검증하는 평가가 아니라 잠재적인 강화제 후보를 도출한 결과입니다. 시간·상황·동기에 따라 선호도는 변하므로 주기적으로 재평가하고, 실제 제공 시 표적행동이 증가하는지 확인해야 합니다.

상위 잠재적 강화제 종합 결과 (평가 방법별 결과 요약)

선택된 날짜 회차의 질문하기, 관찰하기, 시행 기반 평가에서 도출된 상위 잠재적 강화제와 각 평가별 실제 측정 결과입니다.
